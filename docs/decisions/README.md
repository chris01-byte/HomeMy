# Decisions

Use this directory for durable design decisions that change a contract, architecture boundary, safety assumption, or deployment behavior.

## File Name

Use YYYY-MM-DD-short-decision.md. Keep one decision per file.

## Required Format

# Decision title

Status: proposed, accepted, superseded, or rejected.

## Context

What concrete question required a decision?

## Decision

What is selected, and what is explicitly not selected?

## Evidence

Measured result, source reference, or test that supports the decision.

## Impact

Affected contracts, packages, hardware, and privacy or safety implications.

## Validation

Checks actually run and their results.

## Risks and Rollback

Known limits and a safe way to reverse or disable the change.

## Context Rule

The current decision is summarized in CURRENT_STATE.md. Older records stay here and are loaded only when relevant.
